# Portfólio - Matheus Yukihiro Kubo

🚀 **Portfólio profissional** desenvolvido com React, TypeScript e Tailwind CSS.

## 🌟 Tecnologias Utilizadas

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Build**: Vite
- **Deploy**: GitHub Pages
- **Ícones**: Lucide React

## 📋 Funcionalidades

- ✅ Design moderno e responsivo
- ✅ Seções para Hero, Sobre, Competências, Experiência, Projetos e Contato
- ✅ Animações suaves e efeitos visuais
- ✅ Integração com vídeos demonstrativos
- ✅ Links para redes sociais profissionais

## 🎯 Deploy no GitHub Pages

### Opção 1: Deploy Automático (GitHub Actions)

1. Faça push do código para a branch `main`
2. O GitHub Actions irá automaticamente fazer o deploy
3. Acesse: `https://[seu-usuario].github.io/portifolho/`

### Opção 2: Deploy Manual

```bash
# Instalar dependências
npm install

# Fazer build
npm run build

# Fazer deploy
npm run deploy
```

## 📦 Scripts Disponíveis

- `npm run dev` - Inicia servidor de desenvolvimento
- `npm run build` - Cria build de produção
- `npm run preview` - Visualiza build localmente
- `npm run deploy` - Faz deploy para GitHub Pages

## 🔧 Configuração

### Para usar com seu nome de usuário:

1. Altere a linha `base: '/portifolho/'` no arquivo `vite.config.ts` para `base: '/[seu-usuario].github.io/'`
2. Substitua `[seu-usuario]` pelo seu nome de usuário do GitHub
