# 🎯 PASSO MAIS IMPORTANTE: Criar Repositório no GitHub

## 📱 Acesse: https://github.com/new

## 📝 Preencha assim:

1. **Repository name**: `portifolho`
2. **Description**: `Portfólio profissional de Matheus Yukihiro Kubo - Desenvolvedor Full Stack especializado em UI/UX`
3. **Public** ✓ (marcar como público - necessário para GitHub Pages)
4. **DO NOT** marcar "Initialize this repository with a README"
5. Clique em **"Create repository"**

## 📋 Após criar o repositório, você verá uma página com comandos.

## 🔥 AGORA EXECUTE ESTES COMANDOS NO TERMINAL:

git remote add origin https://github.com/yuhihiro/portifolho.git
git branch -M main
git push -u origin main

## 🚀 Após executar os comandos acima, seu portfólio estará online em:
**https://yuhihiro.github.io/portifolho/**

## ⏰ Tempo estimado: 5-10 minutos para o deploy completar

## ✅ Você saberá que funcionou quando:
- O push terminar sem erros
- Você conseguir acessar o link do seu portfólio
- As imagens e vídeo carregarem corretamente

## 🆘 Se tiver problemas:
1. Verifique se o repositório foi criado corretamente
2. Confirme que está logado no GitHub
3. Verifique se o nome do repositório é exatamente `portifolho`
